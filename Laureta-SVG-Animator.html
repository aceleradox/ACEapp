📖 Manual do Script — Laureta Editor

Visão geral

O script é uma sequência de comandos, um por linha. Ele automatiza transformações da camada ativa, cria frames em série e monta animações completas. Toda execução é registrada no histórico — um único Ctrl+Z desfaz o script inteiro.

  • Comentários começam com #
  • Argumentos separados por espaço
  • Comandos são case-insensitive
  • Blocos de repetição com repeat N { ... }
  • Se houver erro, o script para no ponto do erro (use Ctrl+Z para reverter)

Transformação da camada ativa

ComandoDescrição
shift <dx> <dy>Desloca os pixels da camada ativa em dx, dy pixels. Pixels que saem da borda são perdidos. Ex: shift 4 0
rotate <90|180|270>Gira a camada ativa em 90, 180 ou 270 graus.
flip <h|v>Espelha a camada ativa horizontal (h) ou vertical (v).
fill <#hex>Preenche a camada inteira com a cor informada. Ex: fill #4CAF50
clearApaga todo o conteúdo da camada ativa.
opacity <0..1>Define a opacidade da camada (ex: 0.5 = 50%).
show / hideExibe / oculta a camada ativa.

Gerenciamento de camadas

ComandoDescrição
layer <n>Seleciona a camada n (0 = primeira / base).
addlayerCria uma nova camada em branco no topo.
duplayerDuplica a camada ativa (insere logo acima).
dellayerRemove a camada ativa.
uplayer / uploayerSobe a camada ativa uma posição.
downlayerDesce a camada ativa uma posição.

Frames / Timeline

ComandoDescrição
newframe / dupframeCria um novo frame copiando o atual (inserido após o atual).
delframeRemove o frame atual.
goto <n>Vai para o frame n (0-based).
clearframeLimpa todas as camadas do frame atual.

Controle de fluxo

repeat N { ... } executa o bloco N vezes. Pode ser aninhado.

repeat 3 {
  shift 2 0
  repeat 2 {
    newframe
  }
}

Exemplo — deslocamento contínuo

Cria 8 frames, cada um 4px à direita do anterior:

repeat 7 {
  newframe
  shift 4 0
}
goto 0

Exemplo — pulsar opacidade

Alterna entre 50% e 100% de opacidade a cada frame:

repeat 4 {
  newframe
  opacity 0.5
  newframe
  opacity 1
}
goto 0

Exemplo — animação com múltiplas camadas

# camada 0 = fundo (fixo)
# camada 1 = objeto animado
layer 1
repeat 10 {
  newframe
  shift 1 0
}
goto 0

Exportação de vídeo e GIF

Os botões na barra superior exportam a animação:

  • ⬇️ SVG — baixa o frame atual como SVG vetorial otimizado.
  • ⬇️ SVG Anim — baixa todos os frames como um SVG com <style> e @keyframes, tocando em loop.
  • 🎞 GIF — gera um GIF animado usando a biblioteca gif.js. Requer internet para baixar o worker.
  • 🎥 MP4 — grava a animação usando MediaRecorder nativo. Se o navegador não suportar MP4, o arquivo é salvo como WebM (o console avisa).
O seletor Escala multiplica a resolução final (ex: 32px × 4 = 128×128). O tamanho máximo é limitado a 1024px por lado para evitar arquivos gigantes.

As exportações de vídeo/GIF compõem as camadas visíveis sobre fundo branco (formatos de vídeo e GIF não suportam transparência total).

Dicas

  • Comandos rodam na ordem em que aparecem.
  • Use goto 0 no final para voltar ao primeiro frame.
  • O botão ▶ Executar script aplica o script como uma única operação desfazível.
  • Tecla Espaço reproduz/pausa a animação.
  • Ctrl+Z / Ctrl+Y desfazem/refazem (funciona também para scripts inteiros).
